# Usage

PRISM provides multiple control interfaces, ranging from a bare-metal CLI to a networked Web GUI and REST API. Choose the interface that best fits your workflow.

## Graphical & Command Interfaces
- **[Web Interface Guide](html/web-interface-guide.md)**: Embedded browser-based control panel for real-time visualization and parameter tuning.
- **[CLI Reference Guide](cli/cli-reference.md)**: Full command-line documentation over USB serial.

## Developer APIs & Integration
- **[REST API Reference](rest/rest-api.md)** / **[Examples](rest/rest-api-examples.md)**: Remote control and automation using JSON requests over Ethernet.
- **[Streaming Guide](stream/streaming-guide.md)** / **[Examples](stream/streaming-examples.md)**: High-frequency TCP data streaming (position, velocity, torque) for logging and analysis.
- **Python Client**: Available in the `client/` directory for programmatic interaction (e.g., Isaac Sim, MuJoCo, ROS 2).
